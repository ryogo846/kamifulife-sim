# 上富良野町 移住生活費・支援金シミュレーター

十勝岳の麓に位置する北海道上富良野町（かみふらのちょう）への移住検討者向けに開発された、**単一ファイル完結型（Zero-Backend）のリアルタイム家計収支・支援金シミュレーター**です。

移住相談窓口や移住相談フェア、および個人のスマートフォンでの閲覧・試算に特化しており、サーバー構築不要でブラウザのみで高速に動作します。

---

## 🌟 主な特徴・機能

1. **リアルタイム家計収支シミュレーション**
   - 全47都道府県の平均生活費データベースを搭載し、現在の居住地と上富良野町での想定コスト（家賃、光熱暖房費、食費、交通・車両維持費等）を即時比較。
   - 季節変動（冬期の灯油暖房費ピーク vs 夏期）に対応。
   - 費目別の数値を直接打ち替えて、家庭ごとの実態に合わせたカスタム試算が可能。
2. **上富良野町 支援パッケージ連動判定**
   - **移住支援金**: 東京圏からの移住・就業要件（テレワーク等）および子ども加算を自動判定。
   - **新築住宅補助金**: 基本100万円に加え、加算メニュー（町内業者施工・道産材利用・子育て／若者世帯※排他）や特別加算（北方型住宅ZERO：＋45万円）の組み合わせをリアルタイム計算（最大245万円）。
   - **中古住宅改修費補助金**: 空き家・中古住宅のリフォーム工事費補助（上限30万円）に対応。
   - **子育て・教育支援**: 高校生までの医療費完全無償化、および高校生までの学校給食費完全無償化（年5.5万円/人）を子どもの人数に応じて完全掛け算で連動。
   - **奨学金返還支援**: 若年就業者向けの実質減額支援（年24万円）の反映。
3. **マルチデバイス最適化（PC ＆ スマホ）**
   - **PC / タブレット版**: 大画面での詳細比較テーブル、Chart.jsによる視覚的な横棒グラフ、およびスマホ誘導用の**「動的QRコード自動生成機能」**を搭載。
   - **スマホ版**: 片手操作に特化し、画面下部に常時追従するスティッキー・サマリーバー、および「①条件入力」「②試算結果」のセグメントタブ切替を実装。
4. **管理画面（基準データ設定）**
   - 年度改定や助成単価の見直しに合わせ、生活費の基準値や補助金の上限額をブラウザ上で自由に変更・保存（LocalStorage保存）可能。端末間同期用のJSONエクスポート/インポート機能も完備。
